— Round 1 recap — Revisiting the six-step workflow 5 min
All equations in Round 2 build on the Round 1 workflow. Starting today, we connect equations to each step.
01Data collection
Decide which variables (X) to collect and what to predict (y). This step requires the most domain knowledge.
02Preprocessing
Handle missing values and outliers, and scale features. Convert the data into a form the model can use.
03Model training
The algorithm learns X→y patterns. Choose the form of f: linear regression, trees, ensembles, and so on.
04Prediction
Feed new X into the trained model to produce ŷ. Apply the model to data it has not seen before.
05Evaluation
Compare predictions (ŷ) with actual values (y). Measure performance using RMSE, R², Accuracy, and other metrics.
06Interpretation and application
Connect model results to practical work. Examine feature importance, interpret coefficients, and identify limitations.

— Why learn to read equations? 5 min
This session is not about becoming a mathematician. Reading and interpreting equations, rather than solving them yourself,is the goal.
📄
When reading papers and documentation
Model specifications, algorithm descriptions, and performance reports include equations. Unfamiliar symbols can make you skip the key points. Knowing the notation lets you see in one line what a model minimizes.
🔍
When results look unusual
To decide whether an R² of 0.99 means a good result or suspected leakage, you need to understand the loss function. Reading equations helps you trace why a particular number appeared.
💬
When explaining and persuading
If you say that one outlier distorted a model, explaining mathematically how squared residuals amplify it makes the explanation more credible. Equations provide evidence for your explanation.
What this session expects — This level is enough

ŷ = f(X) and read it as “feed X into the rule f to obtain ŷ.”
L = Σ(yᵢ − ŷᵢ)²and explain it as “the sum of all squared residuals.”

You do not need to differentiate or calculate it yourself. Read, interpret, and connect it to practical work:that is all.

— What is a function? 8 min
In f(X), f is a function. In one sentence, a function is “a rule that takes an input and produces an output”.

→

Transformation rule
The algorithm belongs here
→

Functions in daily life — Start without equations
Vending machine
Insert KRW 500 → f( ) → One can of cola
Rule: “When KRW 500 is inserted, dispense cola”
Same input → Always the same output
Temperature conversion
100°C → f( ) → 212°F
Rule: f(C) = C × 9/5 + 32
A given input determines exactly one output
Linear regression model
Temperature=72, pressure=3.1 → f( ) → Predicted yield
Rule: f(X) = β₀ + β₁×temperature + β₂×pressure
The β values are learned during training
Decision Tree model
Temperature=72, pressure=3.1 → f( ) → Predicted yield
Rule: if temperature > 70 then ... else ...
Same input, same output — But the rule defining f has a different form

00 Notation — Symbols used in equationsNew 10 min
Equations are a new language. Just as knowing words helps you read sentences, understanding symbols makes later equations much easier to read.
Key notation
Symbol Name Meaning and example
y Actual value (target) The answer the model should predict. A value already present in the data. Examples: actual defect count today, actual yield, actual sales
ŷ Predicted value (y-hat) The model output. Compare it with y to measure the error. ŷ − y = residual. Learning adjusts f to reduce this difference.
X Input feature matrix All variables fed into the model. Uppercase X denotes multiple variables arranged in a matrix. Example: [temperature, pressure, humidity, input quantity, ...] — Each row is an observation; each column is a variable
xj The jth variable A particular variable within X. Lowercase letter + subscript. Example: x₁ = temperature, x₂ = pressure
n Number of observations The number of observations used for training, equal to the number of rows. Example: n = 10,000 means 10,000 observations
β Coefficient In a linear model, a number describing how much y changes when X increases by 1. Determined through training. β₀ = intercept; β₁, β₂, ... = slopes for each variable
ε Error term What the model cannot explain: noise in the real world. The ε term states that some part cannot be fully explained by f(X)
i The ith observation An index pointing to one row of data. yᵢ = ith actual value; ŷᵢ = ith prediction. i runs from 1 to n
Σ Summation The symbol for “add everything.” Common in loss functions. Σᵢ(yᵢ − ŷᵢ)² = “Calculate the squared residual for every i and add them all”
00-A Uppercase and lowercase symbols in equationsNew 6 min
The same letter can mean different things depending on its case. Here are the pairs most often confused.
Uppercase Meaning Lowercase Meaning
X All input variables — A matrix (the whole table) Example: a data table containing temperature, pressure, and input quantity xj One variable within it — One column Example: x₁ = temperature column; x₂ = pressure column
L Loss function — Summarizes the total error in one number Example: L = Σ(yᵢ − ŷᵢ)² ℓ Individual loss for one observation Example: ℓᵢ = (yᵢ − ŷᵢ)² — The error for observation i
N, P Total count — Number of observations (N) or variables (P) N = 10,000 observations; P = 15 variables n, p Specific counts used in calculations (same meaning, with a change in notation) Papers may use these interchangeably — Check the context
β̂ A learned coefficient — The hat (^) marks an estimate β̂ = The value fixed after training, used for prediction. β True value — A theoretical coefficient that is unknown in practice We estimate β using β̂. β itself cannot be directly observed.
The hat (^) — A mark of estimation

When a symbol carries a hat (^), it means “a value estimated through learning or calculation”.

ŷ (y-hat) = A value predicted by the model, rather than the actual y
β̂ (beta-hat) = A coefficient learned during training, rather than the true β

In reality, y and β cannot be known perfectly. We work with their estimates, ŷ and β̂.

“Explain the difference between X and xⱼ using practical data. Which table is X, and which column is x₁ in the data you use?”
00-B How to read mathematical notationNew 6 min
When you first encounter an equation, not knowing where to start can stop you. Read from left to right, turning each symbol into words:that is all.
Reading practice — Break it down step by step
1
ŷᵢ “The ith predicted value” ŷ = prediction; subscript i = the ith observation
2
β₀ + β₁x₁ᵢ “Intercept + (β₁ × the first variable's value in observation i)” β₀ = intercept; β₁ = coefficient of the first variable; x₁ᵢ = the ith value of x₁
3
Σᵢ (yᵢ − ŷᵢ)² “For every i, square the difference between the actual and predicted values, then add them all” Σ = add everything; (yᵢ − ŷᵢ) = residual; ² = square
4
β̂ = argmin L(β) “Call the β that makes L smallest β̂” → This is learning argmin = the β that achieves the minimum; hat (^) = a learned estimate
Three questions to ask when an equation is unfamiliar

① What is on the left? — The value the equation seeks (ŷᵢ, L, β̂, ...)
② What does each symbol on the right mean? — Turn each into words
③ How would you express the whole equation in one sentence? — Summarize it as “Doing X produces Y”

If you can answer these three questions, you have read the equation. You do not need to calculate it.

Reading practice
“Explain RMSE = √(1/n · Σ(yᵢ − ŷᵢ)²) using the three questions. What is on the left, what does each symbol on the right mean, and how would you express it in one sentence?”
01 What does f(X) = ŷ mean? 10 min
In ML, the algorithm corresponds to f. Choosing an algorithm means choosing the form of f.
Key equation The common goal of ML
y = f(X) + ε
y
Actual value
The answer in the data: the target we want to predict.
f(X)
Algorithm output
The prediction produced from X. A different algorithm changes the form of f.
ε
Unexplained remainder
No model explains y perfectly. Noise and unmeasured variables remain.
Different algorithms give f different forms
AlgorithmForm of f(X)Key idea
Linear regression β₀ + β₁x₁ + β₂x₂ + ... Summarize the relationship between X and y as a line or plane. Training determines β.
Decision Tree if x₁ > 70 then ... else ... f is an if–else branching structure. Training determines each split criterion.
Random Forest avg(f₁(X), f₂(X), ..., fₖ(X)) Average the functions from multiple trees. Other functions compensate for one function's errors.
K-means argmin‖xᵢ − μₖ‖² Assign clusters rather than make predictions. Assign each point to the nearest center (μₖ).
What we saw in Round 1
“An algorithm is a tool for finding X → y patterns”
“Trees split with if–else rules”
“Ensembles combine several models”
What we see in Round 2
“Algorithm = Choosing the form of f”
"f(X) = β₀ + β₁x₁ + ..." vs "if x > θ then ..."
“Ensemble = Combining multiple functions f into a final ŷ”
Choosing an algorithm means assuming a form for the data relationship

The decision to use linear regression contains an assumption:
“The relationship between X and y in my data is approximately linear.”

If the relationship changes across regions rather than following a line, linear regression cannot capture it fully. Choosing a tree adopts a different assumption: separate rules for separate regions.

Choosing an algorithm means choosing an equation, which means choosing an assumption. Understand the data first to choose an appropriate assumption.

Discussion question
“What form did f take in a model you use or have seen? Explain the assumption you made by choosing that algorithm.”
02 The ML workflow — Through equations 15 min
Add equations to the six-step Round 1 workflow. Connect each step to what happens mathematically.
01Data collection
(X, y) = {(x⁽¹⁾, y₁), ..., (x⁽ⁿ⁾, yₙ)} Collect n (input, target) pairs. X is an n×p matrix, and y is an n-dimensional vector.
Choosing the variables to include in X is itself domain knowledge. Decisions made before the equations influence overall performance.
02Preprocessing
x_scaled = (x − μ) / σ Handle missing values and outliers, and scale features. Scaling puts variables on a comparable scale.
Without it, variables with larger units, such as salary, distort β. Fair comparison becomes difficult mathematically.
03Model training
β̂ = argmin L(y, f(X; β)) Learning means finding the β that minimizes the loss function L. We examine this equation below.
04Prediction
ŷ_new = f(X_new ; β̂) Apply the learned β̂ to new X: data unseen by the model.
“Now that we have β̂, feeding in new X produces ŷ.”
05Evaluation
RMSE = √(1/n · Σ(yᵢ − ŷᵢ)²) Aggregate differences between yᵢ and ŷᵢ on test data. A flawed evaluation criterion (L) can make a poor model seem good.
This is why Accuracy alone is insufficient for imbalanced data: L does not reflect reality.
06Interpretation and application
Values of β̂ and ∂f/∂xⱼ (variable effects) Read β̂ or decompose each variable's contribution to ŷ. In a linear model, interpret β directly.
For trees and ensembles, Feature Importance examines how often a variable contributes to splits.
Discussion question
“What happens if you choose the wrong loss function L in step 03? Can you think of an example from practice?”
03 What is learning? — The loss function 10 min
“The model learns” = Find the parameter β that minimizes the loss function. This is the mathematical definition of learning in ML.
Break down the learning equation — β̂ = argmin L(y, f(X; β))
β̂ = argmin L(y, f(X; β))
β̂ = The coefficient fixed after training. The hat (^) identifies it as an estimate.
argmin An instruction to “find the β that makes the following expression smallest.” Argument of the minimum — Returns the β that achieves the minimum
L(y, f(X; β)) The loss function summarizes the difference between the actual y and predictions made with the current β in one number. Changing β changes f(X; β), which changes L. Learning adjusts β to minimize L.
Read it in one sentence

β̂ = argmin L(y, f(X; β))

→ “Find the β that minimizes the difference (loss L) between actual y and predicted f(X; β). Call it β̂.”

That is learning. Algorithms differ in the form of f (linear or tree-based) and how L is calculated (sum of squares or impurity), but the structure of “finding parameters that minimize L” is shared by all algorithms.

Example loss function SSE — The training criterion for linear regression
L = Σᵢ (yᵢ − ŷᵢ)²
(yᵢ − ŷᵢ)
Residual
The difference between actual and predicted values for observation i. It may be positive or negative.
(yᵢ − ŷᵢ)²
Squaring
Removes the sign and penalizes large errors more heavily. This is why outliers matter.
Σ
Add everything
Sum errors across all n observations. The entire dataset is considered when adjusting β.
The learning process — How do we find β?
  • ①
    Initialize β with arbitrary values
    f(X) is still poor, and the difference (residual) between ŷ and y is large.
  • ②
    Calculate L (loss) using the current β
    L = Σ(yᵢ − ŷᵢ)² — One number expressing how poor the current β is
  • ③
    Adjust β in a direction that reduces L
    Linear regression can calculate β directly with an equation. Deep learning finds it iteratively using gradient descent.
  • ④
    Once L is sufficiently small, fix β̂ = Training complete
    This β̂ is the parameter used later for prediction (step 04).
Why outliers pull the regression line: the mathematical explanation

If an outlier has yᵢ = 1000 and ŷᵢ = 50, its residual = 950 and squared residual = 902,500.
If a normal point has yᵢ = 52 and ŷᵢ = 50, its residual = 2 and squared residual = 4.

One outlier contributes hundreds of thousands of times more to L than a normal point, creating an overwhelmingly strong pull toward the outlier.
This explains mathematically the Round 1 observation that outliers distort the regression line.
