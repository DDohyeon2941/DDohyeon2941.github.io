— 왜 수식을 읽을 줄 알아야 하는가 5 min
이 세션은 수학자가 되기 위한 게 아닙니다. 수식을 "직접 푸는 것"이 아니라 "읽고 해석하는 것"이 목표입니다.
📄
논문·문서를 읽을 때
모델 스펙, 알고리즘 설명, 성능 보고서에는 수식이 섞입니다. 기호가 낯설면 핵심을 건너뛰게 됩니다. 기호를 알면 "이 모델이 무엇을 최소화하는지" 한 줄로 파악됩니다.
🔍
결과가 이상할 때
R²가 0.99가 나왔을 때 "좋다"고 넘길지, "leakage 의심"을 할지는 손실함수가 어떻게 생겼는지 알아야 판단할 수 있습니다. 수식을 읽으면 "왜 이 숫자가 나왔는지"를 역추적하는 힘이 생깁니다.
💬
설명하고 설득할 때
"이상치 하나에 모델이 왜곡됐다"고 말할 때, 잔차 제곱이 이상치를 얼마나 크게 반영하는지 수식 근거로 말할 수 있으면 신뢰도가 달라집니다. 수식은 설명의 근거가 됩니다.

00 Notation — 수식에서 쓰는 기호신규 10 min
수식은 새로운 언어입니다. 단어를 먼저 알아야 문장을 읽을 수 있듯이, 기호 의미를 잡아두면 이후 수식이 훨씬 빠르게 읽힙니다.
핵심 기호 정리
기호 이름 의미 & 예시
y 실제값 (target) 모델이 맞춰야 하는 정답. 데이터에 이미 존재하는 값. 예: 오늘 실제 불량 수, 실제 수율, 실제 판매량
ŷ 예측값 (y-hat) 모델이 출력한 값. y와 비교해서 얼마나 틀렸는지 측정. ŷ − y = 잔차(residual). 이 차이를 줄이는 방향으로 f를 조정하는 게 학습.
X 입력 변수 행렬 모델에 넣는 변수 전체. 대문자 X는 변수가 여러 개(행렬)임을 의미. 예: [온도, 압력, 습도, 투입량, ...] — 행: 관측값 하나 / 열: 변수 하나
xj j번째 변수 X 안에서 특정 변수 하나를 가리킬 때. 소문자 + 아래첨자. 예: x₁ = 온도, x₂ = 압력
n 데이터 건수 학습에 사용한 관측값의 수. 행(row) 수와 같음. 예: n = 10,000이면 1만 건의 관측 데이터
β 계수 (coefficient) 선형 모델에서 "X가 1 증가할 때 y가 얼마나 변하는지" 나타내는 숫자. 학습을 통해 결정됨. β₀ = 절편(intercept), β₁, β₂ ... = 각 변수의 기울기
ε 오차항 (error) 모델이 설명하지 못한 나머지. 현실의 노이즈. 수식엔 항상 ε이 붙음 — "f(X)로 완벽히 설명되지 않는 부분이 있다"는 선언
i i번째 관측값 데이터 한 행(row)을 가리키는 인덱스. yᵢ = i번째 실제값, ŷᵢ = i번째 예측값. i는 1부터 n까지
Σ 합산 (sum) "전부 더해라"는 기호. 손실함수 등에서 자주 등장. Σᵢ(yᵢ − ŷᵢ)² = "모든 i에서 잔차²를 구해서 다 더해라"
00-A 수식에서 대문자와 소문자의 차이신규 6 min
수식에서 같은 알파벳이라도 대문자냐 소문자냐에 따라 의미가 달라집니다. 가장 자주 헷갈리는 쌍을 정리합니다.
대문자 뜻 소문자 뜻
X 입력 변수 전체 — 행렬(표 전체) 예: 온도·압력·투입량이 모두 들어있는 데이터 표 xj 그 안의 변수 하나 — 열(column) 하나 예: x₁ = 온도 열, x₂ = 압력 열
L 손실함수(Loss function) — 전체 오차를 하나의 숫자로 요약 예: L = Σ(yᵢ − ŷᵢ)² ℓ 관측값 하나의 개별 손실 예: ℓᵢ = (yᵢ − ŷᵢ)² — i번째 한 건의 오차
N, P 전체 수 — 데이터 건수(N) 또는 변수 수(P) N = 10,000건, P = 15개 변수 n, p 실제 계산에서 쓰이는 구체적인 수 (의미는 같지만 스케일 표시 용도) 논문마다 혼용하는 경우 있음 — 맥락으로 확인
β̂ 학습으로 구한 계수 — "추정값"을 의미하는 hat(^) 기호 β̂ = 학습 완료 후 확정된 값. 예측에 실제로 쓰이는 계수. β 참값(true value) — 실제로는 알 수 없는 이론적 계수 우리가 β̂로 β를 추정하는 것. β 자체는 관측 불가.
hat(^) 기호 — "추정했다"는 표시

수식에서 기호 위에 ^ (hat)이 붙으면 "학습이나 계산을 통해 추정한 값"이라는 뜻입니다.

ŷ (y-hat) = 모델이 예측한 값 (실제 y가 아님)
β̂ (beta-hat) = 학습으로 구한 계수 (참값 β가 아님)

현실에서 y와 β는 완벽히 알 수 없습니다. 우리가 다루는 건 항상 추정값인 ŷ와 β̂입니다.

확인 질문
"X와 xⱼ의 차이를 실무 데이터로 설명해보세요. 지금 쓰는 데이터에서 X는 어떤 표이고, x₁은 어떤 열인가요?"
00-B 수식 기호를 읽는 법신규 6 min
수식을 처음 볼 때 어디서부터 읽어야 할지 모르면 멈추게 됩니다. 왼쪽에서 오른쪽으로, 기호를 하나씩 말로 바꾸는 것이 전부입니다.
읽기 훈련 — 단계별로 풀어보기
1
ŷᵢ "i번째 예측값" ŷ = 예측값, 아래첨자 i = i번째 관측값
2
β₀ + β₁x₁ᵢ "절편 + (β₁ × i번째 관측의 첫 번째 변수 값)" β₀ = 절편, β₁ = 첫 번째 변수의 계수, x₁ᵢ = x₁의 i번째 값
3
Σᵢ (yᵢ − ŷᵢ)² "모든 i에 대해, 실제값과 예측값의 차이를 제곱한 것을 다 더한다" Σ = 전부 더해라, (yᵢ − ŷᵢ) = 잔차, ² = 제곱
4
β̂ = argmin L(β) "L을 가장 작게 만드는 β를 β̂라고 부른다" → 이것이 학습 argmin = 최솟값을 만드는 β, hat(^) = 학습으로 구한 추정값
낯선 수식을 만났을 때 하는 세 가지 질문

① 왼쪽은 무엇인가? — 이 수식이 구하려는 값 (ŷᵢ, L, β̂ ...)
② 오른쪽의 기호들은 각각 무엇인가? — 하나씩 말로 바꿔보기
③ 전체를 한 문장으로 말하면? — "X를 하면 Y가 된다" 형태로 요약

이 세 질문에 답할 수 있으면 그 수식을 "읽은" 것입니다. 계산은 못 해도 됩니다.

읽기 연습
"RMSE = √(1/n · Σ(yᵢ − ŷᵢ)²) 를 세 질문으로 풀어보세요. 왼쪽은 무엇이고, 오른쪽 기호들은 각각 무엇이며, 전체를 한 문장으로 말하면?"
01 f(X) = ŷ 란 무엇인가 10 min
ML에서 알고리즘은 f에 해당합니다. 어떤 알고리즘을 쓰느냐 = f의 형태를 무엇으로 결정하느냐의 문제입니다.
핵심 수식 ML의 공통 목표
y = f(X) + ε
y
실제값
데이터에 존재하는 정답. 우리가 맞춰야 할 목표.
f(X)
알고리즘의 출력
X를 넣었을 때 나오는 예측. 알고리즘이 바뀌면 f의 형태가 달라짐.
ε
설명 못 한 나머지
어떤 모델도 y를 완벽히 설명할 수 없음. 노이즈, 미측정 변수.
알고리즘마다 f의 모양이 다르다
알고리즘f(X)의 형태핵심 아이디어
선형 회귀 β₀ + β₁x₁ + β₂x₂ + ... X와 y 사이를 직선(평면)으로 요약. β가 학습으로 결정됨.
Decision Tree if x₁ > 70 then ... else ... f가 if-else 분기 구조. 각 분기 기준이 학습으로 결정됨.
Random Forest avg(f₁(X), f₂(X), ..., fₖ(X)) 트리 여러 개의 f를 평균. 한 f의 실수를 다른 f들이 상쇄.
K-means argmin‖xᵢ − μₖ‖² 예측이 아니라 군집 할당. 가장 가까운 중심(μₖ)에 배정.
1라운드에서 본 것
"알고리즘은 X → y 패턴을 찾는 도구"
"트리는 if-else로 나눈다"
"앙상블은 여러 모델을 합친다"
2라운드에서 보는 것
"알고리즘 = f의 형태를 결정하는 것"
"f(X) = β₀ + β₁x₁ + ..." vs "if x > θ then ..."
"앙상블 = 여러 f를 결합해 최종 ŷ"
알고리즘 선택 = 데이터 관계의 형태를 가정하는 것

"선형 회귀를 쓴다"는 결정에는 하나의 가정이 숨어 있습니다:
"내 데이터에서 X와 y의 관계가 대략 직선에 가깝다."

만약 실제 관계가 직선이 아니라 구간마다 달라지는 패턴이라면, 선형 회귀는 그 패턴을 다 담지 못합니다. 이럴 때 트리를 선택하는 것은 "구간별로 따로따로 규칙을 만든다"는 다른 가정을 택하는 것입니다.

결국 알고리즘 선택은 수식 선택이고, 수식 선택은 가정 선택입니다. 데이터를 먼저 이해해야 올바른 가정을 고를 수 있습니다.

"지금 쓰거나 봤던 모델에서 f는 어떤 형태였나요? 그 알고리즘을 선택할 때 어떤 가정을 한 셈인지 말해보세요."
02 ML 전체 흐름 — 수식 관점으로 15 min
Round 1의 6단계 흐름 위에 수식을 얹어봅니다. 각 단계에서 수식적으로 무슨 일이 벌어지는지 연결합니다.
01데이터 수집
(X, y) = {(x⁽¹⁾, y₁), ..., (x⁽ⁿ⁾, yₙ)} n개의 (입력, 정답) 쌍을 모읍니다. X는 n×p 행렬, y는 n차원 벡터.
어떤 변수를 X에 넣을지 결정하는 것 자체가 도메인 지식 — 수식 이전 단계에서의 판단이 전체 성능을 좌우합니다.
02전처리
x_scaled = (x − μ) / σ 결측 처리, 이상치 처리, 스케일링. 스케일링은 "변수들의 단위를 통일"하는 것.
안 하면 단위가 큰 변수(연봉 등)가 β를 왜곡합니다. 수식 입장에서 공정한 비교가 불가능해집니다.
03모델 학습
β̂ = argmin L(y, f(X; β)) 손실함수 L이 최소가 되는 β를 찾는 것 = 학습. 이 수식을 아래에서 자세히 봅니다.
04예측
ŷ_new = f(X_new ; β̂) 학습으로 구한 β̂를 새 X에 적용. 모델 입장에서 처음 보는 데이터(unseen data)에 적용하는 단계.
"β̂를 구했으니 이제 새 X를 넣으면 ŷ가 나온다."
05평가
RMSE = √(1/n · Σ(yᵢ − ŷᵢ)²) test 데이터에서 yᵢ와 ŷᵢ 차이를 집계. 평가 기준(L)이 잘못되면 잘못된 모델을 좋다고 판단.
불균형 데이터에서 Accuracy만 보면 안 되는 이유 — L이 현실을 반영 못 하기 때문입니다.
06해석·적용
β̂ 값, ∂f/∂xⱼ (변수 영향) β̂를 읽거나 각 변수가 ŷ에 얼마나 기여하는지 분해. 선형 모델은 β 자체로 해석.
트리/앙상블은 Feature Importance로 "분기에 얼마나 자주 쓰였는지"를 보는 방식.
토론 질문
"03단계에서 L(손실함수)을 잘못 정하면 어떤 일이 생길까요? 실무에서 떠오르는 예시가 있나요?"
03 학습이란 무엇인가 — 손실함수 10 min
"모델이 학습한다" = 손실함수가 최소가 되는 파라미터 β를 찾는다. 이것이 ML에서 학습의 수학적 정의입니다.
학습 수식 분해 — β̂ = argmin L(y, f(X; β))
β̂ = argmin L(y, f(X; β))
β̂ = 학습이 끝난 뒤 확정되는 계수. hat(^)이 붙어 "우리가 추정한 값"임을 표시.
argmin "뒤에 오는 식을 가장 작게 만드는 β를 찾아라"는 명령어. argument of the minimum — 최솟값을 만드는 β를 반환
L(y, f(X; β)) 손실함수. 현재 β로 예측했을 때 실제값 y와 얼마나 차이나는지를 숫자 하나로 요약. β가 달라지면 f(X; β)가 달라지고, 그러면 L이 달라짐. β를 조정해 L을 최소화하는 것이 학습.
한 문장으로 읽기

β̂ = argmin L(y, f(X; β))

→ "실제값 y와 예측값 f(X; β)의 차이(손실 L)를 가장 작게 만드는 β를 찾아라. 그게 β̂다."

이것이 학습의 전부입니다. 알고리즘마다 f의 모양(선형이냐, 트리냐)과 L의 계산 방식(제곱합이냐, 불순도냐)이 다를 뿐, "L을 최소화하는 파라미터를 찾는다"는 구조는 모든 알고리즘이 동일합니다.

손실함수 예시 SSE — 선형 회귀의 학습 기준
L = Σᵢ (yᵢ − ŷᵢ)²
(yᵢ − ŷᵢ)
잔차
i번째 관측에서 실제값과 예측값의 차이. 양수/음수 모두 가능.
(yᵢ − ŷᵢ)²
제곱
음수를 없애고, 큰 오차에 더 큰 페널티. 이상치에 민감해지는 이유.
Σ
전부 더하기
n개 관측값 전체의 오차를 합산. β를 조정할 때 전체 데이터를 고려.
학습의 흐름 — β를 어떻게 찾는가
  • ①
    β를 임의의 값으로 초기화
    아직 f(X)가 형편없는 상태. ŷ와 y의 차이(잔차)가 크다.
  • ②
    현재 β로 L(손실) 계산
    L = Σ(yᵢ − ŷᵢ)² — 숫자 하나로 "지금 β가 얼마나 나쁜지" 표현
  • ③
    L이 줄어드는 방향으로 β 조정
    선형 회귀는 수식으로 β를 직접 계산 가능. 딥러닝은 반복(gradient descent)으로 찾음.
  • ④
    L이 충분히 작아지면 β̂ 확정 = 학습 완료
    이 β̂가 이후 예측(04단계)에서 쓰는 파라미터.
이상치가 회귀선을 당기는 수식적 이유

이상치 yᵢ = 1000, ŷᵢ = 50이면 잔차 = 950, 잔차² = 902,500.
정상 포인트 yᵢ = 52, ŷᵢ = 50이면 잔차 = 2, 잔차² = 4.

L에서 이상치 하나의 기여가 정상 포인트의 수십만 배. β를 이상치 쪽으로 당기는 힘이 압도적으로 강해집니다.
