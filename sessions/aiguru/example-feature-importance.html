Limitations of this result

A categorical feature such as operator ID can receive structurally low MDI even when it matters, because a binary indicator has only one candidate threshold, 0.5. Continuous features such as temperature and pressure have hundreds of candidate thresholds.
It also gives no direction: these numbers alone do not reveal whether higher or lower temperatures predict more defects.

02 OOB Permutation Importance
Code
# Measure performance loss after shuffling a feature in OOB observations
# Requires oob_score=True
model = RandomForestRegressor(n_estimators=100, oob_score=True, random_state=42)
model.fit(X_train, y_train)

# Baseline: R² on OOB observations before shuffling
# Not the training-set score
baseline = model.oob_score_  # Example: R² = 0.84

from sklearn.inspection import permutation_importance

# Shuffle feature j, measure OOB performance, and compare with baseline
# importance_j = baseline_score - permuted_score
result = permutation_importance(
  model, X_train, y_train,
  n_repeats=10,    # Repeat shuffling 10 times and average
  random_state=42
)

# result.importances_mean: mean decrease in R² per feature

The ranking differs from MDI

Operator ID ranked last by MDI at 0.07, but second by OOB permutation at 0.26.

MDI gives categorical operator IDs low scores because they have fewer candidate thresholds. OOB permutation instead measures how much performance declines when the feature’s information is removed, avoiding that threshold-count bias.

Using only MDI could have led you to incorrectly remove operator ID as noise.

Reading the summary plot

Temperature: red points (high values) concentrate on the right → higher temperature contributes to higher predicted defect rates.
Operator ID: a particular ID (red) concentrates on the right → defects are concentrated for particular operators, a pattern hidden by MDI.
Humidity: points concentrate near 0 → little influence on predicted defect rates.

MDI and OOB tell you how important a feature is. A summary plot also shows the direction and the values associated with its contribution.

The session’s key message

Removing operator ID as noise based only on MDI would discard an important feature.
OOB permutation checks importance through actual performance, while SHAP reveals direction, such as higher predicted defects for a particular operator. Together they support a more convincing operational explanation.
