🧱 Data Architecture

원천 데이터의 의미와 품질을 검증하고, 서로 다른 데이터를 일관된 기준으로 연결해 학습과 운영에 활용할 수 있는 구조를 설계합니다. 메타데이터 관리, 정합성 검증, 데이터 정렬·정규화, 적재 및 관계 설계를 중심으로 경험을 정리했습니다.

AIguru · 검증 중심의 제조 검사 데이터 ETL

검사 파일의 메타데이터를 먼저 검증·적재하고, DB의 검증 정보를 이용해 개별 범프 측정값을 필터링하는 파이프라인입니다. PRE와 COINING 검사 데이터를 동일한 물리적 범프 기준으로 연결해 분석·학습용 데이터셋을 구성합니다.

  1. 메타데이터 추출과 검증: 파일 경로·이름과 SOP 내부 메타데이터에서 lot, strip, 공정, 검사기, 시각을 추출하고 시간·공정·검사 순서·품질 기준의 정합성을 확인합니다. 검증 결과는 로그와 플래그로 남깁니다.
  2. 적재 대상 선정과 DB 구성: 검사 현황과 lot·공정별 요약을 바탕으로 유효한 대상을 선정하고, 메타데이터·요약·검증 플래그를 Azure SQL에 적재합니다.
  3. DB 기반 필터링과 정규화: DB의 메타데이터를 이용해 BUMP 측정 파일을 추가 필터링하고, SOP 기준으로 좌표를 정렬하며 판정값과 측정값을 정규화합니다.
  4. Staging과 데이터 관계 설계: 파일별 범프 데이터를 Parquet으로 staging하고, PRE–COINING 간 동일 범프를 매칭해 ML에 사용할 수 있는 데이터셋으로 연결합니다.

구축 및 적용: 약 5만 개의 검사 결과 파일에서 5천 행의 학습 데이터셋을 구성하고, 전처리·모델 학습·평가·대시보드 초안 구현과 1차 PoC·현장 테스트를 수행했습니다. 운영 자동화 이전 단계까지 직접 설계·구현했습니다.

문서 데이터 표준화 및 구조 설계

  • 원천 데이터 분석: 문서별 표현 차이와 정보의 맥락을 검토했습니다.
  • 데이터 표준화: 서로 다른 표현을 공통 기준으로 정리하고 일관성을 검토했습니다.

AIguru · Round 1 — ML 개념과 실무 해석

  1. ML 전체 흐름과 선형 회귀

    데이터 수집부터 평가·적용까지의 흐름과 회귀 계수, 과적합, 다중공선성, R² 해석을 다룹니다.

  2. 트리 모델과 앙상블

    Decision Tree의 분기와 예측, Bagging·Boosting의 차이, 변수 중요도를 설명합니다.

    보조 예제: MDI · OOB Permutation · SHAP
  3. 클러스터링과 유사도

    Hard·Soft Clustering, 거리와 유사도 선택, 스케일링에 따른 변화와 군집 결과 해석을 다룹니다.

    보조 예제: MinMax 스케일링과 표준화 비교
  4. 성과지표와 모델 평가

    회귀·분류 지표의 의미와 한계, 중요한 구간의 성능을 확인하는 방법을 정리합니다.

  5. 결과를 믿으면 안 되는 경우 초안 자료

    Data Leakage, 편향, 분포 변화, 과적합과 타깃 정의를 통해 모델 신뢰성을 점검합니다.

  6. 시계열 데이터와 검증 초안 자료

    시간 의존성, 데이터 누수, 시점 기반 검증, 재학습과 배포 후 입력 문제를 다룹니다.

AIguru · Round 2 — 수식으로 다시 보는 ML

  1. ML 전체 흐름과 수식 언어 초안 자료

    함수와 수학 기호, 입력·예측값의 관계, 손실함수를 통해 학습의 의미를 설명합니다.

  2. 선형 회귀 수식
