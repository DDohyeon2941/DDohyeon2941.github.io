이용 패턴을 반영한 공간 단위 생성

Development of an enhanced base unit generation framework for predicting demand in free-floating micro-mobility

IET ITS, 2024, 1저자

고정 격자의 크기·경계가 수요 예측에 미치는 MAUP를 다룹니다. 이용량이 적은 지역을 결합하고 시간 패턴과 거리를 함께 사용해 예측의 공간 단위를 구성했습니다.

  • 방법: 기본 격자 → 주요·보조 격자 결합 → 시공간 군집화
  • 결과: 두 도시의 RMSE 개선, Minneapolis의 MAPE는 악화

연구 문제

자유 이동형 이동 수단은 대여소가 없어 수요를 공간 단위로 집계해야 합니다. 같은 이용 기록도 격자의 폭과 경계에 따라 0 수요와 높은 수요의 분포가 달라집니다. 단순히 격자를 크게 만드는 방법은 표적의 규모도 바꾸므로, 예측 개선과 집계 효과를 구분해야 합니다.

접근 방법

  1. 대표점 설정: 기본 격자를 네 하위 격자로 나누고 이용이 한쪽에 집중되면 대표점을 조정합니다.
  2. 주요·보조 격자 결합: 일평균 이용량으로 두 유형을 구분하고 가까운 주요 격자에 보조 격자를 결합합니다. 결합 수를 제한하며, 결합되지 않은 보조 격자도 별도 단위로 정리합니다.
  3. 시공간 군집화: 24시간 이용 비율의 코사인 유사도와 거리 기반 유사도를 곱해 결합합니다. 비인접·대각 인접 쌍의 공간 유사도를 0으로 두고 계층적 군집화로 최종 단위를 구성합니다.
실험 설정과 전체 흐름도

Kansas City의 2019년, Minneapolis의 2022년 7–8월 공유 전동킥보드 기록을 사용했습니다. 250m·500m·750m 격자와 비교하고, 단순한 LSTM에 시간별 수요와 달력 정보를 입력했습니다. 7월을 학습에, 8월을 평가에 사용하며 학습 구간 안에서 fixed-origin 검증을 수행했습니다. 각 실험은 5회 반복했습니다. 목표값은 log1p 변환으로 학습하고 원래 단위로 복원해 평가했습니다.

기여

제1저자로 연구에 참여했습니다. 원고의 저자 기여에는 개념화, 집필, 데이터 정리, 소프트웨어, 방법론과 시각화가 명시되어 있습니다. 예측 모델을 복잡하게 만드는 대신 집계 단위를 설계한 연구입니다.

도시와 지표에 따라 달라지는 결과

전체 공간 단위(All), 500m 기준 격자와 제안 방식 비교 · 원고 Tables 1–2
도시 RMSE: 500m → 제안 MAPE: 500m → 제안
Kansas City 1.7601 → 1.5868 0.7115 → 0.6875
Minneapolis 0.8521 → 0.7776 0.6905 → 0.7226

오차는 낮을수록 좋으며 MAPE는 비율로 표기했습니다. MAPE는 실제 수요가 0인 사례를 제외합니다. 집계 단위 자체가 달라져 절대오차의 규모도 변할 수 있습니다.

두 도시에서 RMSE가 줄었지만 Minneapolis의 MAPE는 커졌습니다. 위치가 도로 단위로 기록된 자료의 특성과 0 수요 처리에 따라 해석이 달라집니다. 또한 원고는 공간적 연결성을 보장하지 못한다는 한계와 파라미터 추가 검토의 필요성을 명시합니다.
