소수 클래스의 어려운 표본을 보존하는 노이즈 필터링

Improved noise-filtering algorithm for AdaBoost using the inter-and intra-class variability of imbalanced datasets

JIFS, 2022, 1저자

AdaBoost에서 어려운 소수 클래스 표본을 노이즈로 과도하게 제거하는 문제를 다룹니다. 클래스별 가중치 분포에 다른 임계값을 적용하고, 원본 및 노이즈 주입 자료에서 표본 보존과 AUROC를 평가했습니다.

  • 방법: 클래스별 평균 기준과 분포 비대칭을 고려한 두 임계값
  • 평가: 11개 데이터셋·노이즈 10–40%·AUROC와 표본 보존

연구 문제

AdaBoost는 반복해서 틀린 표본의 가중치를 높입니다. 불균형 데이터에서는 정보가 있는 소수 클래스 표본도 높은 가중치를 받기 쉬워, 모든 클래스에 같은 필터링 기준을 사용하면 소수 클래스의 정보가 과도하게 사라질 수 있습니다.

접근 방법

  • Case 1 · 클래스별 평균: 다수·소수 클래스 각각의 평균 가중치에 조정 계수를 곱해 별도의 임계값을 설정합니다.
  • Case 2 · 분포의 비대칭: 클래스별 가중치 분포의 퍼짐과 비대칭을 반영합니다. 동일한 사분위수가 생기는 문제를 줄이기 위해 15·85백분위수와 중앙값을 사용합니다. 두 백분위수가 같으면 필터링을 건너뜁니다.
  • 학습 반영: 임계값을 넘는 표본의 가중치를 0으로 두고, ORBoost·RUSBoostWO의 기존 필터링 단계를 대체합니다.
원본·노이즈 주입 실험 설정

표와 결론에 제시된 11개 불균형 데이터셋에서 CART 깊이 1, 부스팅 50회, 층화 5분할 교차 검증의 30회 반복으로 평가했습니다. 주요 지표는 AUROC입니다. 클래스 비율을 유지하면서 합성 표본에 반대 클래스 라벨을 부여해 노이즈를 주입했습니다. 이웃 거리 비율에 비례하는 Direct와 반비례하는 Inverse 표본 선택을 비교하고 노이즈 수준은 10–40%를 10% 간격으로 변경했습니다.

기여

제1저자로 클래스 간 분류 난이도 차이를 필터링에 반영하는 방법을 연구했습니다. 클래스별 임계값과 불균형 비율을 유지하는 노이즈 주입 실험을 함께 제시했습니다.

표본 보존은 개선되지만 성능은 조건에 따라 다름

AUROC 평균값으로 높을수록 좋습니다. 원본 데이터의 특정 모델·조건에 대한 사례이며 전체 데이터셋의 평균이나 노이즈 주입 결과가 아닙니다.

소수 클래스가 노이즈로 판정되는 비율이 줄고 여러 조건에서 예측도 개선됐지만, KC1에서는 개선되지 않았습니다. Case 1이 대체로 Case 2보다 좋은 결과를 보였고, RUSBoostWO와 결합한 Case 2는 같은 백분위수 때문에 필터링이 중단되는 한계를 보였습니다. 소수 클래스 보존 자체를 성능 개선과 동일하게 보지 않습니다.
