Efficient oversampling tailored to each dataset

An efficient method to determine sample size in oversampling based on classification complexity for imbalanced data

ESWA, 2021 · First author

I proposed a way to select dataset-specific oversampling sizes using fewer synthetic samples than full class balancing. Classification complexity adjusts the augmentation size, maintaining or improving classification performance under multiple experimental conditions.

  • Contribution: dataset-specific augmentation with fewer samples than full balancing
  • Evaluation: 16 datasets, 4 boosting methods, repeated 5-fold validation

Research problem

Oversampling involves how many samples to generate as well as where and how to generate them. Datasets with the same imbalance ratio can have different class overlap and neighbor relationships. I used this classification difficulty to determine augmentation size instead of treating full class balancing as the default goal.

Approach

Proposed augmentation size O p = (majority-class count − minority-class count) × T
With 0 ≤ T ≤ 1, the number generated does not exceed that required for full balancing. Cluster-wise augmentation uses each cluster’s generation requirement and complexity T c .

  • F1: Transforms the Fisher discriminant ratio of features into a complexity measure between 0 and 1.
  • F2: Calculates the proportion of samples in the overlap region between classes, modified to include boundary samples in discrete features.
  • N1·N2: Uses within- and between-class neighbor distances and differences in neighbor labels. The measures are modified to consider k neighbors rather than 1 and to focus on the minority class.
Experimental setup and global vs. local complexity

I evaluated SMOTEBoost, RAMOBoost, WOTBoost, and k-means SMOTEBoost on 16 imbalanced benchmarks. The last method also compared global complexity with cluster-level local complexity. Experiments used depth-1 CART, 25 boosting iterations, and 30 repetitions of 5-fold cross-validation. AUC was the main metric, with paired t-tests against full balancing (Balance) on the same splits.

Contributions

As first author, I investigated how to determine a suitable oversampling size for each dataset. Instead of uniformly generating enough samples to equalize class counts, I selected smaller augmentation sizes suited to the classification characteristics of datasets and clusters. The experiments show that generation can be reduced while maintaining or improving classification performance under multiple conditions.

Under these conditions, some cases used fewer synthetic samples and significantly improved AUC. Some datasets deteriorated under other boosting methods, so these results do not imply that half the full-balancing size is sufficient in every setting. Boundary samples, noise prevalence, and multiclass extensions remain areas for further study.
