학위과정 데이터 분포에 맞는 학습

석사·박사과정에서는 불균형 데이터의 학습 편향을 연구했습니다. 어려운 소수 클래스 표본을 노이즈로 지워도 되는지, 모든 데이터셋을 같은 규모로 증강해야 하는지를 다뤘습니다. 표본 수만 맞추기보다 클래스의 분포와 겹침에 맞춰 학습 방법을 조정하는 데 관심을 뒀습니다.

석사 · 효율적인 오버샘플링 · 박사 · 양방향 학습 편향 방지

현업 실제 데이터로 학습과 평가 구성

현업에서는 제조 데이터를 연결하고 정렬해 분석·모델 학습에 사용할 데이터셋을 구성했습니다. 서로 다른 기록이 같은 대상을 나타내는지, 예측 시점에 실제로 확보할 수 있는 정보인지를 확인해야 했습니다. 모델을 적용하는 일에는 데이터의 대응 관계와 사용 맥락을 검증하는 과정이 함께 필요했습니다.

제조 데이터 검증과 연결 · 시계열 정렬과 ML 파이프라인
