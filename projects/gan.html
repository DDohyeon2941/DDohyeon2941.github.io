불균형 이미지 데이터의 GAN 기반 증강

2019 대학원 프로젝트 · 2023 개인 후속 연구

소수 클래스 이미지를 생성해 분류 학습을 보완하는 연구입니다. 단순히 생성 수를 늘리는 것에 더해, 생성 모델이 소수 클래스를 충분히 학습하는지와 생성 이미지의 라벨이 유효한지를 검토했습니다.

문제와 맥락

클래스 수가 불균형하면 분류 모델이 다수 클래스에 치우칠 수 있습니다. GAN으로 소수 클래스를 늘리는 접근도 생성 모델 자체가 다수 클래스에 편향되면 한계가 있습니다. 생성량, 클래스 조건, 이미지의 품질과 다양성을 함께 고려하는 것이 문제였습니다.

2019년 대학원 프로젝트와 2023년 개인 후속 실험은 별도 코드와 설정으로 보존되어 있습니다. 두 시기의 결과를 동일 조건의 성능 비교처럼 다루지 않습니다.

수행 역할

2019년 프로젝트의 실험 자료와 2023년 개인 후속 연구를 정리했습니다. 2023년 기록에서는 여러 생성 목적함수와 분류 평가, 경계 부근 생성에 관한 실험을 확인할 수 있습니다. 2019년의 세부 개인 분담은 별도로 명시하지 않습니다.

접근 방법

불균형 데이터와 분류 평가

MNIST와 CIFAR-10에서 클래스별 표본 수를 달리하고 생성 모델을 학습합니다. 소수 클래스의 생성 이미지를 실제 학습 데이터와 결합한 뒤 LeNet·ResNet 계열 분류기로 평가하는 흐름입니다. 정확도뿐 아니라 F1과 G-mean 등 클래스 불균형을 고려한 지표를 사용합니다.

생성 모델의 차이

  • CGAN은 클래스 라벨을 생성 조건으로 사용합니다.
  • ACGAN은 판별기에 클래스 예측 과제를 함께 둡니다.
  • WGAN과 WGAN-GP는 학습 목적함수와 제약을 바꾸어 생성 학습을 다룹니다.
  • BAGAN 계열은 오토인코더 사전 학습과 클래스별 잠재 표현을 활용합니다. 합성곱 변형에서는 이미지의 공간 구조를 다룹니다.

경계 부근 표본의 의미

후속 실험에서는 결정 경계 부근의 생성 표본을 살폈습니다. 어려운 유효 표본인지, 클래스가 모호하게 섞인 이미지인지, 생성 오류인지 구분해야 하므로 경계에 가깝다는 이유만으로 유용한 증강이라고 판단할 수 없습니다.

적용 범위

공개 아카이브에는 학습 코드, 생성 이미지와 모델 기록이 있습니다. 실험 수행 자료와 향후 연구 방향을 구분하며, 정렬된 비교 결과가 없는 조건에 개선율이나 통계적 우월성을 추가하지 않았습니다.

증강의 효과를 평가하려면 이미지의 현실성·다양성·라벨 타당성과 최종 분류 성능을 함께 확인해야 합니다. 오래된 실험 자료를 보존한 저장소이므로 현재 환경의 완전한 재현 패키지로 보장하지 않습니다.
