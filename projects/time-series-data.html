제조 시계열 데이터 정렬과 ML 파이프라인

현업 프로젝트 · 공개 범위를 일반화한 설명

수집 시점과 간격이 서로 다른 제조 데이터를 모델 학습과 평가에 사용할 수 있도록 정리했습니다. 시간 정렬뿐 아니라 예측 시점에 실제로 사용할 수 있는 정보인지 확인하는 데 중점을 뒀습니다.

목차

문제와 맥락

서로 다른 출처의 기록은 같은 시간 기준으로 곧바로 비교하기 어렵습니다. 기록된 시점과 정보가 실제로 유효한 시점을 검토하지 않으면 관계가 어긋나거나 미래 정보가 학습 입력에 섞일 수 있습니다.

목표는 데이터를 한곳에 모으는 데 그치지 않고, 분석과 실제 사용 시점의 의미가 일치하는 학습 자료를 구성하는 것이었습니다.

수행 역할

데이터 검증과 전처리, 시계열 정렬, 모델 학습·평가 흐름 구성에 참여했습니다. 공개 이력의 범위에는 대시보드 프로토타입과 PoC·현장 테스트 경험도 포함됩니다.

접근 방법

시간 기준과 데이터 품질 검토

자료마다 수집 간격과 기록 의미가 다른 점을 검토하고, 비교 가능한 기준으로 정리했습니다. 누락이나 불일치를 정상적인 관측처럼 취급하지 않도록 검증했습니다.

학습과 사용 시점의 일치

예측하려는 시점에 확보할 수 있는 정보를 기준으로 입력을 구성했습니다. 전처리와 특징 구성의 기준이 학습·검증·사용 단계에서 일관되는지 확인했습니다.

평가와 확인

단일 예측 점수뿐 아니라 실제 사용 맥락에서 오차가 어떤 의미를 갖는지 검토했습니다. 프로토타입과 테스트를 통해 데이터를 해석하고 모델 결과를 확인하는 흐름을 구성했습니다.

적용 범위

데이터 준비, 모델링·평가와 프로토타입 검토까지의 경험을 설명합니다. 전체 운영 시스템의 배포 여부나 정량 성과는 확인된 공개 범위에 포함되지 않습니다.

실제 데이터 필드, 파일, 내부 구현, 처리량과 화면을 공개하지 않고 시계열 데이터 작업의 일반적인 문제와 판단 기준만 설명합니다.
