데이터 품질 차이를 고려한 OOD 일반화

개인 구현 기록이 있는 연구 실험 · 수행 소속 미기재

훈련 환경마다 라벨 오류의 정도가 다를 때 IRM의 규제 항을 어떻게 조정할지 실험했습니다. Colored MNIST에서 환경별 데이터 품질과 입력 변화에 대한 민감도를 규제 설계에 반영했습니다.

  • 실험: 환경별 라벨 품질이 다른 Colored MNIST
  • 방법: IRM 규제의 환경 가중치·입력 민감도 조정

문제와 맥락

훈련 데이터에서 잘 맞는 상관관계가 다른 환경에서는 뒤집힐 수 있습니다. Colored MNIST는 숫자 이미지의 색과 정답의 상관관계를 환경마다 바꾸어 이 문제를 실험합니다. 여기에 환경별 라벨 오류 차이가 있으면 모든 환경을 같은 신뢰도로 다루는 규제가 적절한지 질문할 수 있습니다.

기존 소개의 OOD Detection보다, 공개 구현은 분포가 다른 환경에서도 예측을 유지하려는 OOD 일반화에 해당합니다.

수행 역할

공개 코드의 작성 기록과 저장소 설명에는 IRM을 바탕으로 규제 항을 수정한 개인 구현이 남아 있습니다. 기존 IRM 및 관련 공개 연구 구현을 출발점으로 사용했습니다. 수행 기관이나 수업 여부는 자료에 명시되지 않아 소속을 임의로 정하지 않았습니다.

접근 방법

환경과 라벨 오류 설정

숫자를 두 클래스로 나누고 색과 라벨의 관계를 훈련 환경과 평가 환경에서 다르게 설정합니다. 코드에서는 훈련 색상 오류 확률 0.1·0.2와 평가 확률 0.9를 사용하며, 훈련 환경의 라벨 오류 수준도 0%와 50%로 달리합니다. 이는 실험 조건이며 성능 수치가 아닙니다.

비교 구현

일반 학습 기준선, 기본 IRM, 환경별 가중치를 조정한 버전, 환경과 샘플 수준의 규제를 추가한 버전으로 실험 파일을 분리했습니다. 품질 추정에는 이진 분류 손실을 사용하고 별도 모델의 정보를 활용하는 구현이 포함됩니다.

입력 민감도를 규제에 반영

수정 버전은 입력에 작은 변화를 주었을 때 모델 출력이 얼마나 달라지는지 유한 차분으로 계산합니다. 이 민감도에 클래스별 가중치를 적용한 항을 IRM의 환경별 규제와 함께 사용하도록 구성했습니다.

적용 범위

Colored MNIST를 이용한 연구 실험이며 실제 서비스의 이상 샘플 탐지 시스템은 아닙니다. 반복 실험의 훈련·평가 정확도와 규제 가중치를 기록하고 시각화하는 코드가 있습니다.

공개 자료에서 검증 가능한 최종 성능 비교표를 확인하지 못했으므로 제안 방법의 우수성이나 개선율을 주장하지 않습니다. 원본 실험 코드를 현재 환경에서 재실행한 상태도 아닙니다.
