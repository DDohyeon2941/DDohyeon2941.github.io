OOD generalization with differences in data quality

Coursework & personal projects · Course assignment

I experimented with adjusting the IRM penalty when label noise differs across training environments. In Colored MNIST, the regularization design reflected environment-specific data quality and sensitivity to input changes.

  • Experiment: Colored MNIST with different label quality across environments
  • Method: environment weighting and input sensitivity in IRM regularization

Problem and context

Correlations that fit training data can reverse in another environment. Colored MNIST tests this by varying the relationship between image color and target labels across environments. With additional differences in label noise, the question is whether regularization should trust every environment equally.

I incorporated environment-specific data quality into regularization to investigate OOD generalization across distributions.

My role

For a course assignment, I modified penalties in existing IRM and related implementations and built experiments reflecting data-quality differences between environments.

Approach

Environments and label noise

Digits are grouped into two classes, with color–label relationships differing between training and evaluation environments. The code uses training color-error probabilities of 0.1 and 0.2 and an evaluation probability of 0.9; training label-error levels differ at 0% and 50%. These are experimental settings, not performance results.

Comparison implementations

Separate experiment files cover standard learning, basic IRM, adjusted environment weights, and additional environment- and sample-level regularization. Quality estimation uses binary classification loss, with some implementations incorporating information from a separate model.

Input sensitivity in regularization

Modified versions estimate output changes under small input perturbations using finite differences. Class-weighted sensitivity terms are combined with IRM’s environment-specific penalty.

Scope

This was a Colored MNIST course assignment. I implemented recording and visualization of training/evaluation accuracy and regularization weights across repeated experiments.

The project implemented an experimental structure combining environment-specific regularization with input sensitivity. Final performance comparisons require further validation.
