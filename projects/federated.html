Federated learning experiments with Flower

SeoulTech database course · Team project

Can simply aggregating models produce a good global model when clients have different data quality? Our team compared aggregation strategies in Flower and experimented with controlling updates from clients with incorrect labels.

Problem and context

In federated learning, clients train on their own data and the server aggregates model updates. Because data remain distributed, inaccurate training data on some clients can affect the global model.

The project examined two questions. MNIST experiments compared server aggregation strategies. CIFAR-10 experiments combined clean-label clients with clients whose labels were partly shuffled to examine data-quality effects.

My role

I participated in a course team project with Ji Hyo Kim and Seong Cheol Kim. The team implemented Flower server/client experiments, aggregation comparisons, and update control for data-quality differences.

Approach

Comparing aggregation strategies

After receiving initial server weights, clients train locally and return updates. The server aggregates updates and computes loss and accuracy on separate evaluation data. We repeated this process to compare FedAvg, FedAdagrad, FedAdam, and FedYogi.

Clients with different data quality

CIFAR-10 experiments used 5 clean-data clients and 5 clients with some randomly reassigned labels, varying the correctness of the learning signal rather than the images themselves.

Controlling updates

We tested model-weight norm filtering and gradient-norm clipping during local learning. Clients implemented SGD with optional clipping; the server implemented aggregation selection and global-model evaluation.

Scope

Results and limitations

In the MNIST experiment, FedAdam and FedYogi converged faster or performed better than FedAvg, while FedAdagrad performed worse.

CIFAR-10 global accuracy was 64.13% with clean updates and 59.23% when noisy updates were included. Filtering and clipping did not improve performance in this experiment, indicating that update magnitude alone did not resolve data-quality issues.

These values apply to the course-project settings. Actual inter-institution operation and privacy guarantees were outside the evaluation scope.
