Emergency exit sign recognition for people with visual impairments

SeoulTech IoT course · Team project

Our team built classifiers for emergency exit signs in indoor images and converted them to TensorFlow Lite for lightweight inference. Binary exit-sign recognition and classification of sign types were tested separately.

  • Model: MobileNetV2 for exit-sign presence and sign-type classification
  • Implementation: transfer learning → TFLite quantization → Edge TPU conversion

Problem and context

Emergency exit signs provide important visual information that can be difficult for people with visual impairments to read directly. The project examined the technical feasibility of recognizing exit-related information from camera images.

The public implementation performs image classification. It does not implement object detection locating sign coordinates or actual evacuation-route guidance.

My role

This was a SeoulTech IoT course team project with Sae Rom Lee and Do Hyeon Lee. We prepared image data, trained MobileNetV2 classifiers, and experimented with lightweight conversion.

Approach

Data and classification tasks

We used indoor sign data (ISD), indoor object data (IODD), and self-collected images. Tasks were defined separately as exit/other binary classification and 3-class classification of directional signs, exit signs at the current location, and non-exit images.

Transfer learning

Images were resized to 224×224 and pixel values normalized. We froze ImageNet-pretrained MobileNetV2 weights, added global average pooling and classification layers, and trained them with brightness and flip augmentation.

Training used Adam and categorical cross-entropy, with early stopping based on validation loss. We examined AUC and class-specific predictions.

Conversion for lightweight inference

Keras models were integer-quantized with representative data into TensorFlow Lite, and Edge TPU compilation was tested. The public implementation extends through conversion to lightweight inference formats.

Scope

Validation AUROC was 0.95 for binary classification and 0.9538 for multiclass classification. These are image-classification validation results, not measures of safety in actual evacuation environments.

Errors occurred with backgrounds such as ceilings, walls, and windows. Results come from limited images and validation conditions, requiring further tests across lighting, distance, and sign size. Actual user-facing guidance and safety performance were not evaluated.
