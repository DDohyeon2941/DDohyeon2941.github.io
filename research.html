Research

I study learning and prediction methods suited to data distributions and structure: learning bias in imbalanced data, demand distributions and spatial prediction units in micromobility, and the meaning of pitch situations in sports.

Imbalanced data

  • Strategies to Prevent Biased Learning for Imbalanced Data

    I studied strategies to reduce bias toward either class by adjusting noise filtering, augmentation size, and where synthetic samples are generated.

    Doctoral dissertation, 2025 · Dissertation author

  • Improved noise-filtering algorithm for AdaBoost using the inter-and intra-class variability of imbalanced datasets

    JIFS, 2022 · First author

    This work addresses the excessive removal of difficult minority-class samples as noise in AdaBoost.

    DOI · Code on GitHub

  • An efficient method to determine sample size in oversampling based on classification complexity for imbalanced data

    ESWA, 2021 · First author

    I selected augmentation sizes suited to each dataset using fewer samples than full balancing, maintaining or improving classification performance under multiple experimental conditions.

    DOI · Code on GitHub

  • An Algorithm for Oversampling Size Determination Using Classification Complexity

    My master’s research evaluated whether smaller augmentation sizes than full balancing could provide suitable oversampling for individual datasets.

    Master’s thesis, 2020 · Thesis author
