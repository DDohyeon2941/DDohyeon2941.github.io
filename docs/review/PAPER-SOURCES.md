- 공간 연구: Table 1의 Kansas City와 Table 2의 Minneapolis에서 All 집단의 500m/Prop 값을 사용했습니다. Kansas City의 RMSE 1.7601→1.5868, MAPE 0.7115→0.6875; Minneapolis의 RMSE 0.8521→0.7776, MAPE 0.6905→0.7226입니다. 단위 변경과 0 수요 제외의 영향을 함께 설명했습니다. 원고의 일부 해석 문장은 방향이 모호하여 표의 실제 숫자를 우선했습니다.
